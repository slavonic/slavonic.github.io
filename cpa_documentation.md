## Documentation of the Evangelion CPA font

### Aleksandr Andreev
#### University of Oslo, Faculty of Theology

Evangelion CPA is a font for Christian Palestinian Aramaic (CPA), a Western
Aramaic dialect used by the Melkite Christian community in Palestine,
Transjordan and Sinai between the fifth and thirteenth centuries.[^1]
In earlier scholarly literature, names such as Syro-Palestinian and
Palestinian Syriac were used for this language.

CPA is recorded using a modification of the Esṭrangēlā version of the Syriac
script.[^2] The Unicode standard does not encode a separate set of characters
for CPA, but rather specifies the use of the Syriac block with some
modifications, which are described in Unicode Technical Note 52[^3] and in
this document.

The font itself can be downloaded from the
[Christian Palestinian Aramaic font page](cpa.html).

## Characters

The following characters are used in CPA, and, as in Syriac, Arabic and other
cursive scripts, they have standalone, initial, medial, and final forms. The
user does not need to call these forms directly; rather, the glyph forms are
available in the font and are selected automatically by the rendering software
based on context.

Note the following:

- The joining behavior of Alaph, He, Waw, Sadhe, and Taw differs from
  Classical Syriac. In Classical Syriac these characters are right-joining
  only, but in CPA these characters are dual-joining.
- U+0716 SYRIAC LETTER DOTLESS DALATH RISH is used for Dalath, which does not
  take a dot. The font also provides a dotted Dalath at U+0715, which looks
  like this: <span lang="syr" dir="rtl">ܕ</span>
- Initial, medial, and final forms can be called out of context by entering
  U+200D ZERO WIDTH JOINER, as in:

  <table class="table table-bordered">
  <thead>
  <tr><th style="text-align: center;">Input</th><th style="text-align: center;">Result</th></tr>
  </thead>
  <tbody>
  <tr><td style="text-align: center;"><span lang="syr" dir="rtl">ܐ</span> + ZWJ</td><td lang="syr" dir="rtl" style="text-align: center;">ܐ‍</td></tr>
  <tr><td style="text-align: center;">ZWJ + <span lang="syr" dir="rtl">ܐ</span> + ZWJ</td><td lang="syr" dir="rtl" style="text-align: center;">‍ܐ‍</td></tr>
  <tr><td style="text-align: center;">ZWJ + <span lang="syr" dir="rtl">ܐ</span></td><td lang="syr" dir="rtl" style="text-align: center;">‍ܐ</td></tr>
  </tbody>
  </table>

- Default joining behavior can be overridden by entering U+200C ZERO WIDTH
  NON-JOINER:

  <table class="table table-bordered">
  <thead>

- You can lengthen the joiner between characters (stretch the characters) by
  inserting U+0640 ARABIC TATWEEL between characters:
  <span lang="syr" dir="rtl">ܐܠــܘܗܐ ܐܠܘܗܐ ܐܠـܘܗܐ ܐܠـــــܘܗܐ</span>
  Note that while this character is encoded in the Arabic block, the Unicode
  Core Specification specifies[^4] that it should also be used for the Syriac
  script.

## Diacritical Marks

### Seyome

The seyome is encoded at U+0308 COMBINING DIAERESIS and looks like this
<span lang="syr" dir="rtl">◌̈</span>.

Here are examples of the seyome above all of the theoretically possible
characters:

<span lang="syr" dir="rtl">ܐ̈ ܒ̈ ܓ̈ ܕ̈ ܖ̈ ܗ̈ ܘ̈ ܙ̈ ܚ̈ ܛ̈ ܝ̈ ܟ̈ ܠ̈ ܡ̈ ܢ̈ ܣ̈ ܥ̈ ܦ̈ ܧ̈ ܨ̈ ܩ̈ ܪ̈ ܫ̈ ܬ̈</span>

Note that positioning seyome over Rish results first in the removal of the
character's dot. Here are some sample words with the seyome:

<span lang="syr" dir="rtl">ܐܢ̈ܗ ܐܬ̈ܝܢ ܗܢ̈ܝܢ ܗ̈ܠܝܟ ܡܠܟ̈ܝܢ ܒܢ̈ܝ ܚܝ̈ܝܗܘܢ ܡ̈ܝܐ ܐܒܗ̈ܬܐ ܚܒ̈ܠܝܐ ܣܟ̈ܠܐܢ ܒܬܘ̈ܠܬܐ ܐܘܪ̈ܚܬܗܘܢ</span>

### Single Dot Above

The single dot above is encoded as U+0307 COMBINING DOT ABOVE and looks like
this: <span lang="syr" dir="rtl">◌̇</span>. Here it is placed above all of the
theoretically possible characters:

<span lang="syr" dir="rtl">ܐ̇ ܒ̇ ܓ̇ ܕ̇ ܖ̇ ܗ̇ ܘ̇ ܙ̇ ܚ̇ ܛ̇ ܝ̇ ܟ̇ ܠ̇ ܡ̇ ܢ̇ ܣ̇ ܥ̇ ܦ̇ ܧ̇ ܨ̇ ܩ̇ ܪ̇ ܫ̇ ܬ̇</span>

The dot has a variety of meanings. It can be used as a feminine marker over
Taw or He, as in the following examples:

<span lang="syr" dir="rtl">ܒܛܢܬ̇ ܐܬܥܒܖܬ̇ ܗܘܬ̇ ܥܠܝܗ̇ ܚܬ̇ܗ̇</span>

It can be used to distinguish homonyms, as in:

<span lang="syr" dir="rtl">ܡ̇ܢ ܡܢ</span>

It can occur as a vocalization mark over Alaph or Waw (and He?):

<span lang="syr" dir="rtl">ܐ̇ܦܪܟܘܣ ܙܘܢܐ̇ ܗ̇ܐ ܘ̇</span>

**NB**: U+0740 SYRIAC FEMININE DOT is not used.

### Single Dot Below

The dot below is encoded at U+0323 COMBINING DOT BELOW and looks like this:
<span lang="syr" dir="rtl">◌̣</span>. Here the dot is positioned below all of the
theoretically possible characters:

<span lang="syr" dir="rtl">ܐ̣ ܒ̣ ܓ̣ ܕ̣ ܖ̣ ܗ̣ ܘ̣ ܙ̣ ܚ̣ ܛ̣ ܝ̣ ܟ̣ ܠ̣ ܡ̣ ܢ̣ ܣ̣ ܥ̣ ܦ̣ ܧ̣ ܨ̣ ܩ̣ ܪ̣ ܫ̣ ܬ̣</span>

In practice it occurs only below Alaph, Waw, and Yudh, as in these words:

<span lang="syr" dir="rtl">ܟܢܝ̣ܫܬ̇ܐ ܫܘ̣ܡ̇ܝܐ̇ ܩ̇ܠ̈ܐ̣</span>

The dot above and dot below may be combined, by entering them in succession:
<span lang="syr" dir="rtl">ܐ̣̇</span>. The order of entry is not relevant.

If two diacritical marks are entered above a character they are stacked,
indicating that an error has been made: <span lang="syr" dir="rtl">ܒ̇̈</span>.

## Using the Font with LuaLaTeX and XeLaTeX

Because CPA is a cursive script, correct rendering depends on the typesetting
engine applying the font's OpenType shaping features: the selection of the
initial, medial, and final forms, the cursive joining of adjacent letters, and
the positioning of the diacritical marks described above. Not every engine or
font loader does this reliably.

Under XeLaTeX the font may be loaded in the ordinary way with `fontspec`,
since XeTeX shapes complex scripts through HarfBuzz by default:

```latex
\newfontfamily\cpafont{EvangelionCPA}
```

Under LuaLaTeX the font must be loaded with the HarfBuzz renderer:

```latex
\newfontfamily\cpafont[Script=Syriac,Renderer=HarfBuzz]{EvangelionCPA}
```

This is necessary because the font loader's default `node` renderer does not
correctly shape CPA: it fails to select the positional forms and to join
adjacent letters, so that the text appears as a sequence of unconnected
isolated glyphs. The HarfBuzz renderer shapes the script correctly and should
always be used with this font under LuaLaTeX.
